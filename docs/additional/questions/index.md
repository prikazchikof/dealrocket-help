# Другие вопросы

В этой статье собраны ответы о совместной работе в одном аккаунте, переходе на другой email, способах передачи данных в другие системы и коммуникации по найденным контактам.

**Также ищут:** «можно ли работать вместе?», «как изменить email аккаунта?», «можно ли перенести подписку?», «есть ли у DealRocket API?», «что говорит 152 ФЗ?», «что учитывать по ФЗ о Рекламе?».

## Что умеет AI-помощник DealRocket { #ai-helper }

**Также ищут:** «это чат со справкой или полноценный ассистент?», «может ли помощник собрать базу?», «чем отличаются вкладки помощника?».

В чате доступны два сценария. Во вкладке **«Задать вопрос»** помощник отвечает по справке DealRocket: как собрать базу клиентов или обогатить свой список компаний, экспортировать данные, работать с контактами и оплатить сервис.

Во вкладке **«Собрать базу и настроить фильтры»** ассистент поможет описать нужных B2B-клиентов, сформировать выборку и подобрать подходящие фильтры для их поиска.

## Можно ли пользоваться одним аккаунтом нескольким сотрудникам { #shared-account }

**Также ищут:** «можно ли работать под одним логином?», «есть ли доступ для нескольких сотрудников?», «будут ли общими баланс и списки?», «как добавить члена команды?», «как добавить сотрудника в личный кабинет?».

Да. Несколько сотрудников могут работать под одним логином. Баланс контактов, списки и история открытых контактов будут общими для всех пользователей этого аккаунта.

Передавайте данные для входа только доверенным сотрудникам: каждый пользователь общего логина получает доступ к данным и действиям этого аккаунта. Не запускайте несколько экспортов одновременно: операции могут мешать друг другу. Отдельных командных аккаунтов и персональных профилей сотрудников сейчас нет.

## Можно ли изменить email или логин аккаунта { #change-login }

**Также ищут:** «как изменить email аккаунта?», «можно ли поменять логин?», «как перенести подписку на другой email?».

Самостоятельно изменить логин или email существующего аккаунта нельзя. Зарегистрируйте новый аккаунт с нужным email и обратитесь в поддержку через [страницу контактов DealRocket](https://dealrocket.ru/app/contacts).

На новый аккаунт можно перенести активную оплаченную подписку. Перенос списков, истории и ранее открытых контактов не гарантируется.

## Есть ли у DealRocket публичный API { #api }

**Также ищут:** «есть ли у DealRocket API?», «можно ли получать контакты автоматически?», «есть ли готовая интеграция с CRM?».

Публичного API сейчас нет. Значительная часть сведений и контактов собирается и проверяется непосредственно во время работы с выдачей и экспорта, поэтому получить полную базу автоматически по API нельзя.

Полную базу можно передать через экспорт в Excel. Полученный файл нужно самостоятельно импортировать в CRM или другой сервис, который поддерживает такой формат.

## Что учитывать при B2B-коммуникации { #personal-data-and-advertising }

**Также ищут:** «можно ли использовать рабочие контакты из открытых источников?», «как коммуницировать в B2B?», «что учитывать по 152 ФЗ и ФЗ о Рекламе?».

Мы готовим отдельную заметку о том, как выстраивать B2B-коммуникацию с учётом требований законодательства о персональных данных и рекламе.

Если кратко, для делового общения в рамках B2B-коммуникации можно использовать рабочие контакты из открытых ресурсов компании. Основанием выступает законный интерес, а целью — заключение договора. Судебная практика по вопросам персональных данных применительно к B2B-коммуникации практически отсутствует.

В части ФЗ о рекламе важно персонализировать коммуникацию, избегать в рассылках слова «купить» и других прямых рекламных формулировок, а также не использовать роботизированные звонки. Некоторые компании, в том числе крупные, начинают разговор с вопроса «Есть минутка?». Положительный ответ рассматривается как формальное согласие продолжить коммуникацию.
