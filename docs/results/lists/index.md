# Списки и сохранение фильтров

В DealRocket можно сохранить как конкретных сотрудников и компании, так и условия, по которым вы их нашли.

Списки подходят для работы с уже отобранными результатами. Сохранённые фильтры помогают возвращаться к нужной аудитории и повторять поиск по тем же условиям.

## Чем отличаются списки и сохранённые фильтры { #lists-vs-saved-filters }

| Возможность | Что сохраняется | Когда использовать |
|---|---|---|
| **Списки** | Конкретные сотрудники или компании | Когда нужно зафиксировать подходящие записи, проверить их, открыть контакты или подготовить экспорт |
| **Сохранённые фильтры** | Условия поиска | Когда нужно регулярно возвращаться к одной аудитории и получать актуальную выдачу |
| **История поиска** | Недавние наборы фильтров | Когда нужно вернуться к поиску, который вы не сохраняли отдельно |

Сохранённые фильтры не фиксируют состав выдачи. При повторном открытии DealRocket заново применит выбранные условия к актуальной базе. Поэтому количество и состав результатов могут измениться.

Например, можно сохранить фильтры для поиска директоров по маркетингу в IT-компаниях Москвы и периодически возвращаться к этой аудитории, чтобы находить новых сотрудников и компании.

## История поиска { #search-history }

DealRocket автоматически сохраняет последние поиски. Чтобы вернуться к ним, откройте раздел **«история поиска»** в основном меню.

В нём доступны две вкладки:

- **«История»** — последние 50 уникальных наборов фильтров;
- **«Сохранённые фильтры»** — поиски, которые вы сохранили под понятным названием.

В карточке поиска отображаются основные условия и дата последнего использования. Нажмите на название или кнопку **«Открыть поиск»**, чтобы снова применить эти фильтры.

Если повторить поиск с теми же условиями, он поднимется в начало истории.

## Как сохранить настроенные фильтры { #save-filters }

1. Настройте поиск и дождитесь загрузки выдачи.
2. Откройте **«Экспорт и действия»**.
3. Выберите **«Сохранить фильтры»**.
4. Укажите понятное название, например «IT-компании Москвы» или «Финансовые директора в производстве».

Сохранённый поиск появится в разделе **«история поиска»** на вкладке **«Сохранённые фильтры»**. Также можно открыть вкладку **«История»** и сохранить нужный поиск оттуда.

## Чем отличаются списки людей и компаний { #list-types }

В DealRocket есть два типа списков.

| Тип списка | Что в нём сохраняется |
|---|---|
| **Список людей** | Конкретные сотрудники, которых вы выбрали на вкладке **«Люди»** |
| **Список компаний** | Компании, которые вы выбрали на вкладке **«Компании»** |

Если открыть список компаний и перейти на вкладку **«Люди»**, DealRocket покажет всех найденных сотрудников этих компаний. Это позволяет сначала собрать нужные организации, а затем искать внутри них сотрудников разных функций и управленческих уровней.

## Как сохранить результаты { #save-list }

**Также ищут:** «как сохранить выдачу?», «как добавить найденные данные в список?», «где потом найти подборку?», «можно ли продолжить работу позже?».

1. Выделите нужные строки в поисковой выдаче.
2. Откройте **«Экспорт и действия»**.
3. Выберите **«Сохранить в список»**.
4. Создайте новый список или выберите существующий.
5. Откройте результат в разделе **«Мои списки»**.

Тип списка зависит от вкладки, на которой вы сохраняете результат. Давайте спискам понятные названия, например «HR в IT-компаниях» или «Компании с HR».

## Как очистить сохранённый список { #clean-list }

**Также ищут:** «как удалить неподходящие компании?», «как удалить часть списка?», «как убрать отдельных сотрудников из списка?».

Внутри списка можно продолжать использовать фильтры. Они применяются только к сохранённым данным.

Чтобы убрать неподходящую компанию, откройте вкладку **«Компании»**, выделите её и выберите **«Экспорт и действия» → «Удалить из списка»**. На вкладке **«Люди»** тем же способом можно удалить отдельных сотрудников.

После очистки список можно открыть позже или передать в экспорт.

## Сколько строк можно просматривать в одном списке { #list-limit }

**Также ищут:** «какой лимит просмотра списка?», «почему в списке видно не больше 10 000 строк?», «как работать с большим списком?».

За один раз в списке можно просматривать до 10 000 строк. Если выборка больше, разделите её фильтрами, например по регионам, должностям или источникам, и последовательно сохраните части в отдельные списки.

## Как найти руководителей компаний, в которых есть HR { #multi-step-search }

**Также ищут:** «как найти руководителей в сохранённых компаниях?», «как продолжить поиск внутри списка компаний?».

Списки позволяют строить поиск в несколько подходов. Например, так можно найти CEO, владельцев и основателей только в тех компаниях, где уже найден HR.

1. Настройте поиск по нужным компаниям и выберите HR в фильтре **«Функция или департамент»**.
2. На вкладке **«Люди»** сохраните найденных HR в список людей.
3. Переключитесь на вкладку **«Компании»** и сохраните найденные организации в отдельный список компаний.
4. Откройте сохранённый список компаний и переключитесь на вкладку **«Люди»**.
5. Уберите фильтр HR и выберите подходящие значения **«Управленческого уровня»**: основателей, владельцев, директоров и другие нужные руководящие роли.

В результате вы получите руководителей не по всему рынку, а только внутри компаний, где DealRocket уже нашёл HR. По такой же схеме можно сначала отобрать компании по одной роли, а затем найти в них сотрудников другой функции.

## Частые вопросы { #faq }

### Можно ли сохранить результаты без открытия контактов? { #save-without-opening }

Да. Сначала сохраните нужных сотрудников или компании, а контакты открывайте позже, когда список уже проверен.

### Можно ли продолжать фильтровать сохранённые данные? { #filter-saved }

Да. Откройте список в разделе **«Мои списки»** и примените нужные фильтры в левой колонке.

### Как удалить отдельную неподходящую строку? { #remove-one-row }

Выделите её внутри списка и выберите **«Экспорт и действия» → «Удалить из списка»**.
