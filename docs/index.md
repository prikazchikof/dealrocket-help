# Справка DealRocket

DealRocket — сервис для поиска B2B-клиентов и прямых контактов ЛПР в России. Здесь вы разберётесь, как подобрать целевые компании и сотрудников, получить доступные телефоны, email и ссылки на социальные сети, а затем подготовить базу для CRM, рассылок и звонков.

## Выберите сценарий поиска

<div class="grid cards help-card-grid scenario-cards" markdown>

-   :material-filter-outline:{ .lg .middle } **Найти новых клиентов**

    Если у вас ещё нет списка компаний для продаж, соберите его с нуля: найдите организации по отрасли, географии и другим критериям, а затем — ЛПР и сотрудников с доступными контактами.

    [Собрать базу с нуля →](search/index.md){ .help-card-link }

-   :material-table-search:{ .lg .middle } **Найти контакты по своему списку компаний**

    Если целевые компании уже известны, используйте их названия, сайты или ИНН. DealRocket найдёт связанные организации и сотрудников, а для списка сайтов можно запустить отдельное обогащение.

    [Найти контакты по списку →](search/company-list/index.md){ .help-card-link }

-   :material-office-building-outline:{ .lg .middle } **Найти ЛПР в крупном бизнесе**

    Если вы занимаетесь точечными продажами крупному бизнесу, учитывайте бренды, юридические лица и филиалы. Этот сценарий поможет найти несколько ЛПР и точек входа в нужный департамент.

    [Найти ЛПР в крупном бизнесе →](search/large-business/index.md){ .help-card-link }

</div>

Если пока трудно описать, кому именно вы продаёте, сначала подготовьте короткий профиль идеального клиента. Он поможет выбрать фильтры и заранее понять, по каким признакам вы будете оценивать результат.

[Подготовиться к поиску](start/index.md){ .md-button .md-button--primary }

## Что делать с найденной базой

<div class="grid cards help-card-grid result-cards" markdown>

-   :material-filter-check-outline:{ .lg .middle } **Уточнить результаты поиска**

    Уберите нерелевантные компании, ослабьте слишком строгие фильтры и сохраните подходящую выборку, не начиная поиск заново.

    [Уточнить результаты →](search/refine/index.md){ .help-card-link }

-   :material-account-box-multiple-outline:{ .lg .middle } **Открыть контакты и сохранить список**

    Проверьте найденные компании и сотрудников, откройте нужные контакты и сохраните выборку, чтобы вернуться к ней позже.

    [Работать с контактами и списками →](contacts/index.md){ .help-card-link }

-   :material-download-outline:{ .lg .middle } **Экспортировать базу**

    Выгрузите найденные компании и контакты в Excel, чтобы передать их в CRM, систему рассылок или сервис для звонков.

    [Экспортировать базу →](export/index.md){ .help-card-link }

-   :material-account-arrow-right-outline:{ .lg .middle } **Подготовить базу к работе**

    Подготовьте данные к звонкам, email-рассылкам или работе в социальных сетях и выберите подходящий канал для первого контакта.

    [Начать работу с базой →](outreach/index.md){ .help-card-link }

-   :material-database-check-outline:{ .lg .middle } **Проверить качество данных**

    Узнайте, откуда DealRocket получает сведения, как проверяет контакты и что делать, если нужного телефона или email нет.

    [Разобраться в качестве данных →](data-quality/index.md){ .help-card-link }

-   :material-wallet-outline:{ .lg .middle } **Разобраться с тарифом и оплатой**

    Узнайте, чем отличаются тарифы, за что списывается баланс контактов, как получить закрывающие документы, отключить продление или проверить возможность возврата.

    [Перейти к тарифам и оплате →](billing/index.md){ .help-card-link }

</div>
