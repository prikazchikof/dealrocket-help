# Как выгрузить контакты в Excel

Откройте нужную поисковую выдачу или список и выберите **«Экспорт и действия» → «Экспорт в Excel»**.

**Также ищут:** «как скачать базу», «как выгрузить контакты в CRM», «почему в файле звёздочки», «как экспортировать больше 10 000 записей».

## Шаг 1. Выберите записи { #all-or-selected }

Есть два способа экспорта:

- **«Скачать все»** выгружает сплошную часть выборки. Её объём можно задать слайдером или точным количеством записей.
- **«Скачать выделенные записи»** выгружает только строки, которые вы заранее отметили в таблице.

## Шаг 2. Выберите тип контактов { #choose-contacts }

В блоке **«Укажите, какие контакты хотите экспортировать»** выберите контакты сотрудников, контакты компаний или оба типа.

Контакты сотрудников — прямые контакты людей из выборки, а контакты компаний — общие контакты организаций. Один просмотр всех найденных телефонов и email сотрудника или компании считается одним контактом баланса. Если нужны оба типа, выберите обе галочки: сотрудник и компания учитываются отдельно.

Перед экспортом DealRocket покажет, сколько новых контактов будет списано. Уже открытые контакты повторно не тарифицируются.

## Шаг 3. Запустите экспорт и дождитесь файла { #run-export }

Нажмите кнопку скачивания и дождитесь файла. Не запускайте несколько экспортов одновременно.

Экспорт может занять некоторое время: непосредственно перед выгрузкой DealRocket обращается к источникам данных и проверяет контакты в реальном времени. Так в файл попадают наиболее актуальные доступные контакты.

## Почему контакты скрыты звёздочками { #stars }

Звёздочки означают, что этот тип контакта не был выбран для экспорта. Выберите контакты сотрудников или компаний, чтобы DealRocket запросил и добавил их в файл.

Если баланса недостаточно, экспорт остановится до скачивания и предложит уменьшить объём.

## Почему в контактах есть пустые поля { #empty-fields }

Пустое поле означает, что после проверки в реальном времени в источнике не оказалось контакта нужного типа — например, телефона или email. Такие данные не добавляются в файл и не тарифицируются.

Если у той же записи найден другой вид данных, он входит в тот же открытый контакт и не считается отдельным контактом.

## Как выгрузить более 10 000 записей { #over-10000 }

За один экспорт можно выгрузить до 10 000 записей. Для большей выборки используйте один из двух способов.

**Способ 1.** Разделите выборку фильтрами и выгружайте части последовательно. Например, сначала выгрузите директоров, затем руководителей. Можно разделить выборку и по источникам: сначала ВКонтакте, затем LinkedIn и остальные.

**Способ 2.** Откройте нужную выборку и сохраните её в список. Перейдите в список и выгрузите контакты. Затем вернитесь к исходной выборке, включите фильтр **«Контакты закрыты»**, сохраните оставшиеся записи в новый список и выгрузите их оттуда.

Этот подход можно повторять и без списков, но список позволяет в любой момент вернуться к уже обработанной части выборки.

## Частые вопросы { #faq }

### Почему экспорт может идти долго?

DealRocket напрямую обращается к источникам и проверяет контакты перед выгрузкой. Для большой выборки это может занять некоторое время.

### Списывается ли баланс за пустые поля?

Нет. За ненайденные контакты списание не происходит.

### Зачем подключать профиль ВКонтакте?

ВКонтакте — один из источников прямых контактов сотрудников. Подключение профиля позволяет DealRocket запросить оттуда актуальные данные во время экспорта.
