# Как выгрузить контакты в Excel

Экспорт превращает проверенную выдачу или сохранённый список в файл для дальнейшей работы. В одном окне вы выбираете строки и типы контактов, видите предварительный расчёт новых открытий и запускаете подготовку файла. Отдельно открывать каждый контакт перед этим не нужно.

**Также ищут:** «как скачать базу», «как выгрузить контакты в CRM», «почему в файле звёздочки», «как экспортировать больше 10 000 записей».

## Что проверить перед выгрузкой { #before-export }

Сначала просмотрите компании и сотрудников. Если выдача смешанная, исключите повторяющиеся типы неподходящих компаний или сохраните только нужные строки в список. Контакты лучше открывать после отбора, чтобы баланс расходовался на аудиторию, с которой вы действительно планируете работать.

Решите, какие данные нужны следующему процессу:

- прямые контакты сотрудников;
- общие контакты компаний;
- оба типа как два независимых способа связи;
- только демонстрационные строки без открытия закрытых контактов.

Если файл дальше загружается в CRM или сервис рассылок, заранее проверьте обязательные колонки и допустимый объём импорта в этой системе. DealRocket формирует Excel-файл, а правила загрузки зависят уже от выбранной CRM.

## Шаг 1. Откройте окно экспорта { #all-or-selected }

Перейдите в нужную выдачу или в **«Мои списки»**, затем нажмите **«Экспорт и действия»**. В окне **«Экспорт в Excel»** есть два способа выбрать записи.

### Скачать первые N записей { #download-first }

Укажите количество и нажмите **«Скачать все (N)»**. Кнопка выгрузит первые N строк текущей выдачи с учётом активных фильтров. Слово «все» относится к заданному объёму, а не к неограниченному числу найденных результатов.

Такой вариант подходит, если выдача уже однородна и вам не нужно отмечать каждую строку вручную.

### Скачать только отмеченные строки { #download-selected }

Сначала поставьте отметки у нужных компаний или сотрудников, затем нажмите **«Скачать выделенные записи (N)»**. Используйте этот вариант, когда вы проверили строки вручную или хотите выгрузить только небольшую часть списка.

Если общее число результатов ещё не загрузилось, интерфейс может разрешить экспорт только отмеченных строк. Дождитесь расчёта или выберите записи вручную.

## Шаг 2. Выберите контакты { #choose-contacts }

В блоке **«Укажите, какие контакты хотите экспортировать»** доступны варианты:

- **«Экспортировать контакты сотрудников»**;
- **«Экспортировать контакты компаний»**.

У сотрудника и компании разные контактные данные. Один новый просмотр всех доступных контактов сотрудника считается одним контактом баланса; просмотр контактов компании — ещё одним. Если нужные данные уже открывались в вашем аккаунте, повторного списания нет.

Перед подтверждением DealRocket показывает предварительное количество новых контактов. Проверьте выбранные галочки и остаток баланса. Если не выбрать ни одного типа, получится демонстрационный файл: закрытые контактные поля останутся под звёздочками.

## Зачем подключать профиль ВКонтакте { #vk-profile }

ВКонтакте — один из источников прямых контактов сотрудников. Если для выбранных данных требуется обращение к этому источнику, DealRocket покажет соответствующую подсказку в окне экспорта.

Подключите профиль по инструкции интерфейса и затем продолжите выгрузку. Это не означает, что без ВКонтакте в файле не будет никаких данных: результат зависит от источников конкретных строк и выбранных типов контактов.

## Шаг 3. Запустите экспорт и дождитесь файла { #run-export }

Во время выгрузки DealRocket проверяет выбранные контакты в доступных источниках. Поэтому файл не всегда появляется мгновенно, особенно при большом количестве строк.

Оставьте вкладку открытой до начала скачивания и следите за сообщением о прогрессе. Не запускайте несколько одинаковых операций подряд: сначала дождитесь результата или явной ошибки по текущему экспорту.

После скачивания откройте файл и проверьте несколько строк: те ли компании и сотрудники попали внутрь, появились ли выбранные типы контактов, нет ли систематически пустой важной колонки.

## Почему в файле контакты скрыты звёздочками { #stars }

Звёздочки означают, что этот тип контакта не был выбран и открыт во время экспорта. Наиболее частые причины:

1. соответствующая галочка не выбрана в окне экспорта;
2. вы скачали демонстрационный файл без контактов.

Если баланса недостаточно, текущий экспорт останавливается до скачивания и предлагает уменьшить объём. Поэтому в уже полученном файле сначала проверьте выбранные типы контактов. Не повторяйте экспорт вслепую: исправьте настройку и только затем создайте новый файл.

## Почему контактное поле осталось пустым { #empty-fields }

Пустое поле означает другое: DealRocket запросил выбранный тип данных, но после проверки не нашёл его в источнике. Такой пустой результат не тарифицируется.

Если телефон найден, а email отсутствует, открытие всех доступных данных этого сотрудника или компании всё равно считается одним контактом баланса: телефон и email не тарифицируются по отдельности. Используйте найденный способ связи, общий контакт компании, публичный профиль сотрудника или найдите другого человека той же функции.

Имя сотрудника также может отсутствовать в конкретном источнике. Не подставляйте догадку в рабочую базу: сопоставьте должность, компанию и доступную ссылку либо выберите запись, где имя подтверждено.

## Как выгрузить больше 10 000 записей { #over-10000 }

За одну операцию можно выгрузить не более 10 000 строк. Разделите аудиторию на непересекающиеся части, например:

1. по региону или индустрии компании;
2. по управленческому уровню или функции сотрудника;
3. по источнику;
4. по открытым и закрытым контактам;
5. через заранее подготовленные списки.

После каждой части фиксируйте использованные фильтры или название списка. Перед следующим экспортом убедитесь, что новая выборка не возвращает уже обработанные строки.

Один из практичных сценариев: сохранить первую выборку в список и выгрузить её, затем в исходном поиске включить фильтр закрытых контактов и подготовить следующую часть. Проверяйте пересечение перед передачей файлов в работу.

## Что делать, если экспорт не завершается { #export-problems }

Большая выгрузка может готовиться дольше из-за проверки источников. Если прогресс остановился или появилась ошибка:

1. не запускайте несколько копий операции;
2. сохраните ссылку на поиск или название списка;
3. запишите время запуска и выбранный объём;
4. сделайте скриншот сообщения без платёжных и других чувствительных данных;
5. [напишите в поддержку](https://t.me/dealrockets).

## Частые вопросы { #faq }

### Нужно ли сначала открыть контакты, а потом экспортировать?

Нет. Текущий экспорт сам открывает выбранные типы контактов перед созданием файла. Выберите галочки сотрудников и компаний в окне экспорта.

### Списывается ли баланс за пустые поля?

Нет. Пустое поле означает, что этот вид данных не найден после проверки. Все найденные телефоны и email одного сотрудника входят в одно открытие; контакты его компании считаются отдельным открытием.

### Почему кнопка «Скачать все» не выгружает всю многотысячную базу?

Кнопка выгружает указанное количество первых строк, а одна операция ограничена 10 000 записями. Большую выдачу нужно разделить на части.
