# Как начать работать с готовой базой

Файл с контактами — это начало работы, а не готовый результат продаж. Перед первой коммуникацией разделите аудиторию на понятные сегменты, выберите канал, с которым команда готова работать, и подготовьте обращение под роль человека и задачу компании.

**Также ищут:** «что делать после выгрузки», «подойдёт ли база для звонков», «как писать по найденным контактам», «как подготовить базу к работе».

## Шаг 1. Проверьте, что находится в файле { #review }

Откройте несколько строк и сопоставьте их с исходным профилем клиента. Компании должны относиться к нужному рынку, а сотрудники — к функции, которая понимает ваше предложение.

Если в одном файле смешаны разные отрасли, размеры организаций или роли, разделите его. Например, собственникам небольших компаний и руководителям закупок крупного бизнеса обычно нужны разные аргументы и разная длина первого сообщения.

Отдельно проверьте строки без прямого телефона или email. Они не обязательно бесполезны: можно использовать общий контакт компании, публичный профиль или другого сотрудника той же функции.

## Шаг 2. Выберите один основной канал { #channel }

Начните с канала, который команда сможет обрабатывать регулярно:

- **звонки** — когда нужен быстрый диалог и есть прямой или общий телефон;
- **email** — когда предложение проще объяснить письменно и можно подготовить релевантную тему;
- **социальная сеть или мессенджер** — когда найден публичный профиль и такой формат уместен для аудитории;
- **последовательность каналов** — если заранее определено, когда команда переходит от одного касания к другому.

Не выбирайте канал только потому, что в файле много определённого типа контактов. Учитывайте роль человека, привычный способ общения в отрасли и скорость, с которой команда отвечает на реакцию.

## Шаг 3. Сделайте обращение адресным { #message }

Используйте то, что уже известно из DealRocket: имя, должность, компанию и признак, по которому она попала в сегмент. Первое сообщение должно объяснять, почему вы обращаетесь именно к этому человеку и какой простой следующий шаг предлагаете.

Не перечисляйте все возможности продукта и не маскируйте массовое сообщение случайной подстановкой имени. Свяжите предложение с зоной ответственности сотрудника. Руководителю продаж, HR-директору и специалисту по закупкам нужен разный контекст даже внутри одной отрасли.

Если прямого контакта нет, позвоните на общий номер и попросите соединить с конкретным человеком или нужным отделом. В письме на общий адрес укажите получателя и должность в теме и начале текста.

## Шаг 4. Начните с небольшой части сегмента { #first-batch }

Не отправляйте непроверенное сообщение сразу всей базе. Возьмите небольшую однородную часть и посмотрите, что происходит:

- люди не отвечают;
- контакт неактуален;
- отвечает не та роль;
- компания не относится к сегменту;
- предложение не вызывает интереса.

Это разные сигналы. Неактуальный телефон относится к конкретной записи. Ответ «не моя зона ответственности» показывает, что стоит пересмотреть роли. Нерелевантная компания говорит о фильтрах, а отсутствие интереса при точной аудитории — о предложении или сообщении.

## Шаг 5. Верните обратную связь в поиск { #feedback }

После первой серии коммуникаций уточните следующую выборку:

1. исключите повторяющийся тип неподходящих компаний;
2. расширьте функцию, если точная должность оказалась слишком узкой;
3. сохраните самый перспективный сегмент отдельно;
4. найдите других сотрудников в подходящих компаниях;
5. выгрузите следующую часть с обновлёнными критериями.

Так база становится рабочим циклом: поиск → проверка → коммуникация → уточнение. Не смешивайте изменения аудитории и сообщения в одной итерации, иначе будет трудно понять, что повлияло на результат.

## Частые вопросы { #faq }

### Подойдёт ли база для звонков и рассылок?

Да, если вы выбрали соответствующие контакты и подготовили процесс. Для звонков проверьте телефоны и сценарий разговора, для email — адреса, тему и готовность обрабатывать ответы.

### Что делать с неактуальным контактом?

Отметьте причину отдельно, проверьте общий контакт компании или другого сотрудника. Несколько повторяющихся случаев передайте поддержке с примерами.

### Можно ли ожидать одинаковый результат в разных сегментах?

Нет. На ответ влияют рынок, роль, предложение, канал и сообщение. Сравнивайте однородные сегменты и не обещайте команде фиксированную конверсию только на основании размера базы.
