# Как искать клиентов с помощью AI-помощника

В DealRocket есть три способа быстрее начать поиск: AI-помощник подбирает фильтры по вашему запросу, AI-фильтр проверяет уже готовую выдачу, а подборки открывают заранее настроенные аудитории по популярным запросам.

**Также ищут:** «как искать клиентов с помощью AI», «как пользоваться ИИ-помощником», «как отфильтровать список с помощью AI», «где найти готовые подборки».

## Соберите поиск с помощью AI-помощника { #ai-assistant }

AI-помощник переводит обычный текстовый запрос в фильтры DealRocket.

1. Откройте поиск и нажмите **«ИИ-помощник»** над фильтрами слева.
2. Выберите, что для вас важнее: отрасль или вид деятельности компании, крупный бизнес либо департамент и специализация сотрудника.
3. Опишите, кого хотите найти. Пишите про клиента, а не про свой продукт, и используйте один клиентский сегмент за один поиск. Например: «Руководители по маркетингу в интернет-магазинах в Москве с численностью сотрудников от 20 человек».
4. Проверьте предложенные фильтры. На каждом шаге можно выбрать **«Применить фильтр»** или **«Не применять фильтр»** и сразу увидеть, как изменится количество результатов.

После последнего шага DealRocket откроет готовую выдачу. Если в ней остались неподходящие компании, воспользуйтесь инструкцией [по очистке результатов](../refine/index.md).

## Отфильтруйте готовую выдачу с помощью AI { #ai-filter }

AI-фильтр подходит, когда результаты уже собраны, но обычных фильтров недостаточно. Он проверяет каждую компанию или каждого сотрудника по вашей инструкции и сохраняет подходящие записи в отдельный AI-список.

1. Откройте **«Экспорт и действия» → «AI-фильтр списка»**.
2. Выберите готовый пример или сформулируйте свою инструкцию. Используйте доступные в окне переменные, например название и описание компании.
3. Запустите проверку для выбранных строк или всех доступных записей.
4. После обработки откройте новый AI-список в разделе **«Мои списки»**. У каждой записи будет результат **«Подходит: Да / Нет»** и краткая причина.

Например, чтобы оставить B2B-компании, можно написать: «Определи, является ли компания „{{company.name}}“ по описанию {{company.description}} B2B-компанией».

Доступный объём AI-фильтрации указан в самом окне и зависит от вашего тарифа.

## Используйте готовые подборки { #collections }

Подборки — это готовые аудитории для быстрого старта поиска. Они отвечают на популярные запросы, поэтому не нужно настраивать все фильтры вручную.

1. Нажмите **«подборки»** в верхнем меню DealRocket.
2. Переключитесь между подборками по **индустриям** и **должностям**.
3. Выберите аудиторию и нажмите **«Открыть подборку»** — поиск откроется в новой вкладке.

## Что выбрать { #choice }

- Если хотите собрать поиск с нуля по своему описанию — используйте **AI-помощника**.
- Если выдача уже готова и её нужно проверить по дополнительному условию — используйте **AI-фильтр списка**.
- Если ваш запрос уже есть среди популярных сценариев — начните с **подборки**.
