# Фильтры поиска: как они работают

Фильтры помогают перейти от широкой базы DealRocket к компаниям и сотрудникам, которые подходят под вашу задачу. На вкладках **«Люди»** и **«Компании»** набор фильтров немного отличается.

**Также ищут:** «как настроить фильтры DealRocket», «какой фильтр выбрать», «чем ОКВЭД отличается от индустрии», «почему после фильтра мало результатов», «как найти сотрудников по должности».

## Как сочетать фильтры { #how-to-combine }

Фильтры из разных блоков работают одновременно. Например, если выбрать индустрию, город и управленческий уровень, в результатах останутся сотрудники выбранного уровня только в компаниях подходящей индустрии и города.

Несколько значений внутри одного обычного фильтра расширяют выбор: подойдёт любое из них. Отдельные исключения подписаны прямо в интерфейсе — например, **«Содержит каждое из слов»** и **«Компания содержит каждый из выбранных типов индустрий»**.

Добавляйте условия по одному и следите за количеством результатов. Местоположение, ОКВЭД, выручка, численность сотрудников и другие поля заполнены не у всех компаний. Даже подходящая организация не попадёт в выдачу, если выбранного поля у неё нет.

## AI-фильтр { #ai-filter }

### «Подходит ли»

- **Как работает.** Доступен в готовом AI-списке и разделяет записи по результату проверки: **«да»**, **«нет»** или **«ошибка»**.
- **Когда использовать.** Когда AI-фильтрация уже завершилась и нужно отдельно посмотреть подходящие, неподходящие или необработанные записи.
- **Когда не использовать.** В обычном поиске этого фильтра нет. Чтобы проверить новую выдачу по текстовому условию, сначала запустите [AI-фильтр списка](../ai-assistant/index.md#ai-filter).

## Должности { #job-titles }

Этот блок доступен на вкладке **«Люди»**.

### «Управленческий уровень»

- **Как работает.** Объединяет разные варианты написания одного уровня: например, «директор», `director` и сокращённые названия.
- **Когда использовать.** Начинайте с него, если ищете руководителей. Выберите все подходящие уровни, чтобы не потерять сотрудников из-за разного написания должностей.
- **Когда не использовать.** Не оставляйте один слишком узкий уровень, если вам подходят владельцы, директора, C-level и руководители подразделений.

### «Функция или департамент»

- **Как работает.** Объединяет должности по направлению работы. Например, к продажам могут относиться менеджер по продажам, РОП и коммерческий директор.
- **Когда использовать.** Добавляйте после управленческого уровня, когда нужен конкретный департамент: продажи, IT, кадры и другие функции.
- **Когда не использовать.** Не включайте слишком рано: функция заметно уменьшает количество найденных сотрудников.

### «Включить должности»

- **Как работает.** Ищет введённое слово или фразу внутри названия должности.
- **Когда использовать.** Если нужной функции нет в готовом списке или вы ищете специфическую роль, например «клиентский опыт» и `customer experience`.
- **Когда не использовать.** Не начинайте поиск только с одной формулировки должности: одинаковая роль в разных компаниях может называться по-разному.

### «Исключить должности»

- **Как работает.** Убирает сотрудников, в названии должности которых встречается указанное слово или фраза.
- **Когда использовать.** Когда в выдаче регулярно повторяется один неподходящий тип должностей.
- **Когда не использовать.** Не вводите слишком общие слова: вместе с неподходящими ролями можно убрать нужных сотрудников.

### «Год начала работы»

- **Как работает.** Использует дату начала работы в компании, чтобы оставить более свежие записи.
- **Когда использовать.** Когда для задачи особенно важны сотрудники, которые недавно начали работать в организации.
- **Когда не использовать.** Если важнее максимальный охват: дата начала работы указана не у каждого сотрудника, поэтому результатов станет меньше.

### «Работают сейчас»

- **Как работает.** Оставляет текущие связи сотрудника с компанией. По умолчанию фильтр включён.
- **Когда использовать.** Оставьте включённым для обычного поиска действующих сотрудников.
- **Когда не использовать.** Отключайте только тогда, когда вам действительно нужны в том числе прошлые места работы.

### «Включать отделы»

- **Как работает.** Добавляет в результаты записи, относящиеся к отделам компании, а не только к конкретным людям. По умолчанию фильтр включён.
- **Когда использовать.** Оставьте включённым, если полезны любые точки входа в нужное подразделение.
- **Когда не использовать.** Отключите, если в результатах нужны только сотрудники с персональными записями.

## Местоположение { #location }

Местоположение доступно не для всех организаций. Оно чаще находится у компаний и сотрудников, связанных с сообществом в социальной сети.

### «Страна»

- **Как работает.** Оставляет компании и сотрудников из выбранных стран.
- **Когда использовать.** Когда поиск действительно ограничен конкретной страной.
- **Когда не использовать.** Для поиска по всей России страну **«Россия»** лучше не выбирать: основная часть базы уже относится к России, а отсутствие заполненного местоположения искусственно уменьшит выборку.

### «Область»

- **Как работает.** Ограничивает результаты выбранными регионами.
- **Когда использовать.** Для региональных продаж, доставки или услуг с ограниченной географией.
- **Когда не использовать.** Если вы работаете удалённо или по всей стране и не хотите потерять компании без указанного региона.

### «Город»

- **Как работает.** Оставляет компании и сотрудников из выбранных городов.
- **Когда использовать.** Для локального бизнеса и задач, привязанных к конкретному городу.
- **Когда не использовать.** Для федерального поиска или когда город не является обязательным критерием.

## Компания { #company }

### «Найти компании»

- **Как работает.** Находит конкретную организацию по брендовому или юридическому названию и показывает её среди подсказок вместе с сайтом и количеством найденных сотрудников.
- **Когда использовать.** Для точечного поиска в нескольких заранее известных компаниях.
- **Когда не использовать.** Для длинного списка организаций удобнее использовать отдельные поля с названиями, сайтами или ИНН.

### «Ключевые слова в названии компании»

- **Как работает.** Ищет слова и части слов в названиях компаний.
- **Когда использовать.** Когда известны брендовые или юридические названия и нужно получить максимальное количество совпадений. Добавляйте разные варианты написания отдельными строками.
- **Когда не использовать.** Если название короткое или распространённое: в результатах могут появиться одноимённые компании. Для большей точности используйте сайт или ИНН.

### «Сайт компании»

- **Как работает.** Ищет организации по доменам их сайтов.
- **Когда использовать.** Когда у вас уже есть список сайтов целевых компаний и важна точность совпадения.
- **Когда не использовать.** Если нужен максимальный охват: сайт указан не во всех источниках, поэтому часть сотрудников может не найтись.

### «ИННы»

- **Как работает.** Ищет конкретные юридические лица по ИНН.
- **Когда использовать.** Когда важно максимально точно сопоставить организацию с юридическим лицом.
- **Когда не использовать.** Для поиска всей группы компаний или максимального количества сотрудников: ИНН относится к отдельному юридическому лицу и связан не со всеми записями.

### «Телефон компании или человека»

- **Как работает.** Ищет записи по известным номерам телефонов компаний и сотрудников.
- **Когда использовать.** Чтобы определить, есть ли уже известный номер в DealRocket и с какой записью он связан.
- **Когда не использовать.** Для первичного поиска клиентского сегмента — этот фильтр рассчитан на проверку конкретных номеров.

### «Есть сайт»

- **Как работает.** Оставляет только компании, у которых найден сайт.
- **Когда использовать.** Если сайт необходим для дальнейшего изучения компании или вашей коммуникации.
- **Когда не использовать.** Если важен широкий охват: отсутствие сайта в DealRocket не означает, что компания вам не подходит.

## Описание компании { #company-description }

Эти фильтры ищут введённые слова в названиях и описаниях компаний.

### «Содержит любое из слов»

- **Как работает.** Компания попадёт в результат, если найдено хотя бы одно введённое слово — условие **ИЛИ**.
- **Когда использовать.** Для широкого поиска по нескольким близким формулировкам, продуктам или видам деятельности.
- **Когда не использовать.** Не добавляйте общие слова, которые встречаются у компаний из разных сегментов: они добавят много нерелевантных результатов.

### «Содержит каждое из слов»

- **Как работает.** В описании должны присутствовать все введённые слова — условие **И**.
- **Когда использовать.** Когда сегмент определяется сочетанием нескольких обязательных признаков.
- **Когда не использовать.** Не добавляйте много условий сразу: каждое следующее слово сужает выдачу.

### «Не содержит каждое из слов»

- **Как работает.** Каждое введённое значение работает как минус-слово: компания исключается, если такое слово найдено в её названии или описании.
- **Когда использовать.** Чтобы массово убрать повторяющийся неподходящий тип компаний или исключить одну организацию по точному названию.
- **Когда не использовать.** Не используйте широкие слова и короткие корни, которые могут встречаться в описании подходящих компаний.

## Индустрии — отрасли { #industries }

Индустрии собраны из разных источников. Для широкого поиска выбирайте подходящие значения в нескольких группах.

### «Категории из карт»

- **Как работает.** Использует категории, к которым компания отнесена в сервисах с картами. Они доступны для большинства компаний.
- **Когда использовать.** Для локального бизнеса и понятных категорий: магазинов, клиник, ресторанов и других организаций, представленных на картах.
- **Когда не использовать.** Не ограничивайтесь только картами, если ищете B2B-компании, которые могут быть лучше описаны на сайте или в социальной сети.

### «Подборки по семантике»

- **Как работает.** Открывает готовые подборки компаний по заранее настроенным ключевым словам в названиях и описаниях.
- **Когда использовать.** Для быстрого старта по распространённому клиентскому сегменту.
- **Когда не использовать.** Если ни одна подборка точно не описывает вашу аудиторию — добавьте другие типы индустрий или фильтры по описанию.

### «Индустрии из соц. сетей»

- **Как работает.** Использует сферы деятельности из профилей ВКонтакте и LinkedIn.
- **Когда использовать.** Чтобы дополнить поиск данными, которые компании указали в социальных сетях.
- **Когда не использовать.** Не ограничивайте поиск только этим фильтром: он доступен только для компаний и сотрудников из ВКонтакте и LinkedIn.

### «Компания содержит каждый из выбранных типов индустрий»

- **Как работает.** Требует, чтобы компания совпала с выбранными значениями в каждой используемой группе индустрий, а не хотя бы в одной из них.
- **Когда использовать.** Когда нужно повысить точность уже достаточно большой выдачи.
- **Когда не использовать.** В начале поиска: пересечение нескольких групп заметно уменьшает количество результатов.

### «Исключить категории, подборки и индустрии»

- **Как работает.** Убирает компании, относящиеся к выбранным категориям или индустриям.
- **Когда использовать.** Когда неподходящие результаты объединяет одна повторяющаяся индустрия.
- **Когда не использовать.** Не исключайте слишком широкую категорию, если внутри неё могут находиться и целевые компании.

## ОКВЭДы { #okved }

### «Вид деятельности»

- **Как работает.** Фильтрует компании по ОКВЭДам из юридической информации. Это отдельный фильтр, не связанный с блоком индустрий.
- **Когда использовать.** Когда важен зарегистрированный вид деятельности конкретного юридического лица.
- **Когда не использовать.** Для широкого поиска по фактической деятельности компании. Юридическая информация связана не со всеми организациями, поэтому ОКВЭД может очень сильно сократить выдачу.

## Размер компании { #company-size }

### «Выручка — за год»

- **Как работает.** Оставляет компании в выбранных диапазонах годовой выручки. Данные доступны только для организаций, связанных с ИНН.
- **Когда использовать.** Чтобы сначала получить компании нужного масштаба или снять верхнюю часть рынка.
- **Когда не использовать.** Если нужен полный список потенциальных клиентов. Выручка заполнена не у всех компаний, поэтому фильтр сильно уменьшает количество результатов.

### «Количество сотрудников»

- **Как работает.** Оставляет компании в выбранных диапазонах численности. Данные берутся из LinkedIn или юридической информации.
- **Когда использовать.** Когда размер компании — обязательная часть профиля клиента.
- **Когда не использовать.** В начале широкого поиска. Численность известна не для каждой организации, поэтому фильтр сильно сужает выдачу.

## Источник { #source }

### «Источник данных»

- **Как работает.** Оставляет записи, полученные из выбранных источников: ВКонтакте, LinkedIn, сайтов компаний или ЕГРЮЛ.
- **Когда использовать.** Когда нужно проверить конкретный источник или разделить готовую базу на части.
- **Когда не использовать.** Для обычного поиска максимального количества компаний и сотрудников: источники дополняют друг друга, а ограничение одним из них уменьшает охват.

## Наличие контактов { #contacts }

На вкладке **«Люди»** можно отдельно фильтровать контакты сотрудников и их компаний. На вкладке **«Компании»** доступны только условия для компаний.

### «Один сотрудник из компании»

- **Как работает.** Оставляет по одной записи сотрудника на каждую компанию. Фильтр может загружаться дольше.
- **Когда использовать.** Чтобы быстро получить широкий список компаний без большого количества строк из одной организации.
- **Когда не использовать.** Если нужно найти несколько ЛПР или сотрудников разных функций внутри каждой компании. Единственная оставшаяся запись не обязательно будет нужным ЛПР.

### «Есть имя сотрудника»

- **Как работает.** Оставляет персональные записи с доступным именем. Фильтр применяется к сотрудникам из ВКонтакте и ЕГРЮЛ.
- **Когда использовать.** Когда имя необходимо для персонального обращения.
- **Когда не использовать.** Если важнее максимальное количество результатов и вы готовы дополнительно проверить записи без имени.

### Контакты сотрудника: «есть любой контакт», «есть почта», «есть телефон»

- **Как работает.** Оставляет сотрудников, у которых найден хотя бы один прямой контакт либо конкретно email или телефон.
- **Когда использовать.** Выберите условие под основной канал коммуникации.
- **Когда не использовать.** Если готовы связываться через публичный профиль или общие контакты компании: фильтр уберёт сотрудников без прямого телефона или email.

### Контакты сотрудника: «есть мобильный телефон»

- **Как работает.** Оставляет сотрудников с номерами формата `+7 9…`. Загрузка может занимать больше времени.
- **Когда использовать.** Когда для коммуникации нужны именно российские мобильные номера.
- **Когда не использовать.** Если подходят городские и иностранные номера или важна быстрая загрузка широкой выдачи.

### Контакты компании: «есть любой контакт», «есть почта», «есть телефон»

- **Как работает.** Проверяет наличие общих контактов организации, а не прямых контактов сотрудника.
- **Когда использовать.** Если планируете звонить на общий номер, писать на общую почту или хотите иметь запасной способ связи.
- **Когда не использовать.** Не считайте наличие контакта компании гарантией прямого контакта с выбранным сотрудником.

## Открытые контакты { #opened-contacts }

В этом блоке слово «открыты» означает, что для контакта уже нажимали **«Показать контакты»** в вашем аккаунте.

### Контакты сотрудника: «контакты открыты» и «контакты закрыты»

- **Как работает.** Первый вариант оставляет уже полученные контакты сотрудников, второй — контакты, которые ещё не открывали в аккаунте.
- **Когда использовать.** **«Открыты»** — чтобы вернуться к уже полученной базе; **«закрыты»** — чтобы подготовить новую часть выборки без ранее открытых контактов сотрудников.
- **Когда не использовать.** Не включайте оба условия одновременно: одна запись не может быть одновременно открытой и закрытой.

### Контакты компании: «контакты открыты» и «контакты закрыты»

- **Как работает.** Аналогично разделяет уже полученные и ещё не открытые общие контакты компаний.
- **Когда использовать.** Для повторной работы с известными контактами компаний или подготовки новой выгрузки.
- **Когда не использовать.** Не путайте с состоянием контакта сотрудника: контакты человека и организации открываются и учитываются отдельно.

## Количество записей { #record-count }

### «Количество отображаемых записей»

- **Как работает.** Определяет, сколько строк DealRocket загрузит и покажет в текущей выдаче. Доступный максимум зависит от тарифа и указан в интерфейсе.
- **Когда использовать.** Во время настройки поиска начните с небольшого количества, а после проверки увеличьте объём.
- **Когда не использовать.** Не загружайте максимальное количество при каждом изменении фильтров: большая выдача обрабатывается дольше.

Если после добавления условия результатов стало слишком мало, убирайте фильтры в обратном порядке: сначала точные должности и функцию, затем географию, ОКВЭД, выручку и численность сотрудников.
