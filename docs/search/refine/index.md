# Как убрать нерелевантные компании из поиска

Первая выдача редко бывает окончательной: одна индустрия может объединять разные виды бизнеса, а одинаковые слова встречаются в описаниях клиентов, подрядчиков и поставщиков. Не начинайте поиск заново. Найдите повторяющийся признак ошибки, измените одно условие и сравните результат.

**Также ищут:** «как отфильтровать неподходящие компании», «как очистить выдачу», «почему находятся не те организации», «что делать, если результатов слишком мало».

## Шаг 1. Просмотрите выдачу как выборку { #review }

Откройте несколько страниц и не сосредотачивайтесь на одной случайной компании. Ваша задача — увидеть закономерность: какой тип организаций повторяется и почему он прошёл текущие фильтры.

Для каждой неподходящей записи проверьте название, описание, индустрию, сайт и географию. Затем сгруппируйте ошибки. Например:

- вместо подрядчиков попадаются магазины;
- вместо производителей — дистрибьюторы;
- вместо целевого региона — федеральные компании с упоминанием города;
- вместо нужного бренда — партнёры, которые пишут о нём на сайте.

Если у нескольких строк одна причина, её можно исправить фильтром. Единичную компанию проще удалить позже из сохранённого списка.

## Шаг 2. Исключите повторяющийся признак { #exclude-words }

Используйте фильтр **«Описание компании» → «Не содержит каждое из слов»** для характерных слов или фраз из описаний неподходящих компаний.

Предположим, вы ищете компании по загородному строительству, но регулярно видите строителей бассейнов. Слово «бассейн» в исключении уберёт этот тип результата. Если неподходящая компания встретилась только один раз, сохраните полезную часть выдачи и удалите эту строку из списка вручную: фильтр исключения работает с описанием, а не с названием компании.

После каждого изменения снова просмотрите выдачу. Число строк почти наверняка уменьшится; важно, чтобы доля подходящих компаний стала выше.

!!! warning "Не делайте исключение слишком широким"
    Общее слово может встречаться и у целевых компаний. Сначала проверьте несколько описаний, затем добавляйте формулировку, характерную именно для неподходящего типа бизнеса.

## Шаг 3. Проверьте индустрии и географию { #industries-and-location }

Если неподходящие компании слишком разные и у них нет общего слова, вернитесь к исходным индустриям. Возможно, одна из выбранных категорий описывает рынок шире, чем нужно. Отключите её отдельно и сравните результат.

С географией действует тот же принцип. Не сужайте её автоматически до одного города, если компания может обслуживать регион из другого офиса. Решите, что для вас действительно обязательно: юридический адрес, присутствие или возможность работать на нужной территории.

## Шаг 4. Не сужайте роли раньше времени { #roles }

Иногда компании подходят, а сотрудники — нет. Тогда не меняйте фильтры организаций. Проверьте **«Управленческий уровень»**, **«Функцию или департамент»** и точные должности.

Если результатов мало, сначала уберите **«Включить должности»**: конкретная фраза не учитывает все варианты названия роли. Затем расширьте управленческий уровень или функцию. Меняйте одно поле за раз, чтобы понимать причину.

## Шаг 5. Сохраните хорошую часть смешанной выдачи { #save-good-results }

Если часть результатов уже подходит, не теряйте её во время экспериментов.

1. Отметьте подходящие строки.
2. Выберите **«Экспорт и действия» → «Сохранить в список»**.
3. Дайте списку название по сегменту и роли.
4. Продолжите уточнять исходный поиск.
5. При необходимости вернитесь в **«Мои списки»** и удалите отдельные неподходящие строки вручную.

Список помогает отделить готовую часть от новых гипотез. Не смешивайте в одном списке компании, которым нужны разные предложения или разные роли сотрудников.

## Шаг 6. Расширьте слишком маленькую выдачу { #expand }

Если после очистки почти ничего не осталось, возвращайте условия в обратном порядке — от самых жёстких к основным:

1. точное название должности;
2. дополнительные числовые ограничения;
3. узкая функция или управленческий уровень;
4. одна из индустрий;
5. география, если она не является обязательной.

После каждого шага посмотрите, какие записи вернулись. Так вы найдёте границу между полнотой и точностью, а не просто получите большое число строк.

## Шаг 7. Найдите больше людей в подходящих компаниях { #find-more-leads }

Если компании уже подходят, но сотрудников или контактов мало, не расширяйте рынок. Выделите нужные организации, откройте **«Экспорт и действия»** и выберите **«Найти больше лидов»**.

DealRocket дополнительно проверит сайты компаний и социальные сети. Обработка выполняется отдельно, а результат появляется в разделе **«Мои списки»**. Сначала запускайте её только для проверенных компаний, чтобы дополнительный поиск не тратил время на нерелевантную часть выдачи.

## Частые вопросы { #faq }

### Нужно ли удалять каждую неподходящую компанию фильтром?

Нет. Фильтр полезен для повторяющегося типа ошибки. Единичную запись удобнее удалить из сохранённого списка после отбора.

### Почему после исключения пропали подходящие компании?

Скорее всего, слово оказалось слишком общим. Уберите последнее исключение, сравните описания и замените его более характерной фразой.

### Как понять, что поиск уже достаточно точный?

Проверьте несколько страниц. Если компании соответствуют исходному профилю, роли относятся к нужной функции, а один и тот же тип ошибки больше не повторяется, сохраните выборку и переходите к контактам.
