# Как убрать нерелевантные компании из поиска

Если в результатах появились неподходящие компании, не исключайте каждую из них вручную. Сначала найдите общий признак, по которому можно убрать сразу весь нерелевантный тип бизнеса.

**Также ищут:** «как отфильтровать неподходящие компании», «как очистить выдачу», «почему находятся не те организации», «как использовать минус-слова».

## Шаг 1. Исключите повторяющийся признак { #exclude-words }

Посмотрите описания нескольких неподходящих компаний и найдите слова, которые у них повторяются. Добавьте их в фильтр **«Описание компании» → «Не содержит каждое из слов»**.

Например, вы ищете компании по загородному строительству, но в результатах регулярно появляются строители бассейнов. Добавьте слово «бассейн» в исключения — и этот тип компаний исчезнет из результатов.

Если мешает одна конкретная компания, в тот же фильтр можно добавить её точное название. Это неочевидный, но удобный способ убрать единичную организацию прямо из поисковой выдачи.

Если неподходящие компании относятся к одной категории, её также можно исключить в фильтре **«Индустрия»**.

После каждого изменения проверяйте результат. Не используйте слишком общие слова или индустрии: вместе с неподходящими компаниями они могут убрать и нужные.

## Шаг 2. Сохраните результат и дочистите список вручную { #save-good-results }

Минус-словами и исключёнными индустриями можно убрать основную часть неподходящих компаний. Когда результат вас устраивает:

1. Выделите подходящие строки.
2. Выберите **«Экспорт и действия» → «Сохранить в список»**.
3. Откройте результат в разделе **«Мои списки»**.
4. Удалите оставшиеся неподходящие компании вручную.

Массовые ошибки удобнее убирать фильтрами, а единичные строки — уже из сохранённого списка. Так вы получите чистую базу и не потеряете хорошие результаты во время дальнейшей настройки поиска.

## Шаг 3. Найдите больше людей в подходящих компаниях { #find-more-leads }

Если компании уже подходят, но сотрудников или контактов мало, выделите нужные организации, откройте **«Экспорт и действия»** и выберите **«Найти больше лидов»**.

DealRocket дополнительно проверит сайты компаний и социальные сети. Обработка выполняется отдельно, а результат появится в разделе **«Мои списки»**. Запускайте дополнительный поиск только для уже проверенных компаний.

## Частые вопросы { #faq }

### Нужно ли удалять каждую неподходящую компанию фильтром?

Нет. Введите точное название компании в фильтр **«Не содержит каждое из слов»** или удалите её вручную из сохранённого списка.

### Почему после исключения пропали подходящие компании?

Скорее всего, слово или индустрия оказались слишком общими. Уберите последнее исключение и замените его более точным признаком неподходящих компаний.
