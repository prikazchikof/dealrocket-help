# Как собрать базу новых компаний и ЛПР

Этот сценарий подходит, когда конкретного списка компаний ещё нет. Сначала найдите подходящие организации, затем — сотрудников внутри них. После этого уберите из результатов нерелевантные компании.

## Что подготовить { #prepare }

Коротко определите, какие компании и каких сотрудников вы хотите найти. Если пока сложно сформулировать запрос, начните с руководства [по подготовке к поиску](../start/index.md).

## Шаг 1. Выберите индустрии, затем географию { #market }

Сначала откройте фильтр **«Индустрии»**. В нём есть три типа данных:

- **Категории из карт** — категории, к которым компания отнесена в сервисах с картами. Они доступны для большинства компаний.
- **Подборки по семантике** — готовые подборки по ключевым словам в названиях и описаниях компаний.
- **Индустрии из соц. сетей** — сферы деятельности, указанные в профилях ВКонтакте и LinkedIn. Они доступны только для компаний и сотрудников из этих источников.

Выбирайте подходящие варианты во всех трёх группах. Одна компания может быть описана только в одном из источников, поэтому несколько близких индустрий помогут найти больше подходящих результатов.

После индустрий при необходимости добавьте страну, регион или город. Если вы работаете по России, не выбирайте страну **«Россия»**: основная часть базы — российские компании, а местоположение заполнено не у всех организаций. Такой фильтр может искусственно уменьшить выборку.

## Шаг 2. Уберите неподходящие компании { #review-companies }

Иногда компания указывает неверную индустрию или перечисляет слишком много видов деятельности. Из-за этого в результатах появляются неподходящие компании. Их можно убрать через фильтр **«Описание компании» → «Не содержит каждое из слов»**.

### Пример: найти подрядчиков по загородному строительству { #industry-example }

Предположим, вы ищете компании, которые строят частные дома, но вместе с ними находите магазины стройматериалов и компании по строительству бассейнов. Добавьте повторяющиеся слова из их описаний — например, «магазин» или «бассейн» — в фильтр исключений и снова посмотрите выдачу.

Подробнее об очистке выдачи — в статье [«Как убрать нерелевантные компании из поиска»](refine/index.md).

## Шаг 3. Определите ЛПР и сотрудников, через которых можно на него выйти { #seniority }

После поиска компаний выберите, с какими сотрудниками хотите начать коммуникацию.

1. Сначала выберите **«Управленческий уровень»**. Если ищете руководителей, отметьте максимум подходящих вариантов: основателей, владельцев, директоров, руководителей, C-level, партнёров и вице-президентов.
2. Затем при необходимости добавьте **«Функцию или департамент»** — например, продажи, IT или кадры. Этот фильтр сильно уменьшает количество результатов, поэтому применяйте его после управленческого уровня.

### Если нужной функции нет в списке { #job-titles }

Откройте расширенный фильтр по должностям и введите ключевые слова. Например, руководителей, отвечающих за клиентский опыт, можно искать по фразам «клиентский опыт» и `customer experience`.

Не ограничивайтесь одной формулировкой: одинаковая роль в разных компаниях может называться по-разному.

## Необязательно: добавьте размер компании или выручку { #additional-filters }

Численность сотрудников и выручка доступны не для всех компаний. Например, не каждая организация указывает ИНН на своём сайте, поэтому её не всегда удаётся связать с юридическими данными. Любой такой фильтр уменьшает количество найденных результатов.

Используйте эти параметры, если хотите сначала получить компании, которые наиболее точно соответствуют вашему профилю клиента. При этом часть подходящих организаций с незаполненными данными может не попасть в выборку.

## Частые вопросы { #faq }

### Почему результатов слишком мало?

Сначала уберите **«Функцию или департамент»**, затем точные должности, географию, численность или выручку. Проверяйте результат после каждого изменения.

### Что делать, если часть компаний подходит, а часть нет?

Используйте инструкцию [«Как убрать нерелевантные компании из поиска»](refine/index.md). В ней показано, как найти общий признак неподходящих организаций и добавить его в исключения.
