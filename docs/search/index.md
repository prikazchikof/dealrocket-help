# Как собрать базу новых компаний и ЛПР

Этот сценарий подходит, когда конкретного списка компаний ещё нет. Сначала найдите подходящие организации, затем — сотрудников внутри них. После этого уберите из результатов нерелевантные компании.

**Также ищут:** «как найти новых клиентов», «как собрать базу компаний по отрасли», «как найти ЛПР», «как искать по должностям».

## Что подготовить { #prepare }

Коротко определите, какие компании и каких сотрудников вы хотите найти. Если пока сложно сформулировать запрос, начните с руководства [по подготовке к поиску](../start/index.md).

## Шаг 1. Выберите географию и индустрии { #market }

Если для вас важно местоположение компании, укажите страну, регион или город. Затем откройте фильтр **«Индустрии»**. В нём есть три типа данных:

- **Категории из карт** — категории, к которым компания отнесена в сервисах с картами. Они доступны для большинства компаний.
- **Подборки по семантике** — готовые подборки по ключевым словам в названиях и описаниях компаний.
- **Индустрии из соц. сетей** — сферы деятельности, указанные в профилях ВКонтакте и LinkedIn. Они доступны только для компаний и сотрудников из этих источников.

Выбирайте подходящие варианты во всех трёх группах. Одна компания может быть описана только в одном из источников, поэтому несколько близких индустрий помогут найти больше подходящих результатов.

![Пример выбранных строительных индустрий в фильтрах DealRocket](https://dealrocket.ru/app/assets/1-1.png)

*В одном поиске можно выбрать несколько близких индустрий из разных источников.*

## Шаг 2. Уточните результаты поиска { #review-companies }

Сначала посмотрите, какие компании попали в результаты: чем они занимаются, где находятся и соответствуют ли вашему запросу. Если в выдаче повторяется один и тот же неподходящий тип компаний, исключите его и проверьте результат ещё раз.

### Пример: найти подрядчиков по загородному строительству { #industry-example }

Предположим, вы ищете компании, которые строят частные дома. Вместе с ними в результатах могут появиться магазины, многоквартирные застройщики или компании по строительству бассейнов.

1. Посмотрите первые результаты и найдите общий признак неподходящих компаний.
2. Добавьте повторяющиеся слова через **«Описание компании» → «Не содержит каждое из слов»**.
3. Проверьте выдачу ещё раз.

![Пример включающих и исключающих слов в описании компании](https://dealrocket.ru/app/assets/1-2.png)

*Исключения помогают убрать повторяющийся тип неподходящих компаний.*

Подробнее об очистке выдачи — в статье [«Как убрать нерелевантные компании из поиска»](refine/index.md).

## Шаг 3. Выберите, с кем хотите связаться { #seniority }

После компаний выберите сотрудников. Для этого используются два фильтра:

- **«Управленческий уровень»** помогает найти собственников, директоров, руководителей или специалистов независимо от того, как именно написана их должность.
- **«Функция или департамент»** показывает, за какое направление отвечает сотрудник: например, продажи, IT или кадры.

<span id="functions"></span>

Не ограничивайтесь только одной должностью. В разных компаниях одну и ту же работу могут выполнять сотрудники с разными названиями ролей. Выберите подходящий управленческий уровень и направление работы, а затем посмотрите найденные должности.

<span id="additional-filters"></span>

## Необязательно: уточните должность или размер компании { #job-titles }

Точную должность, численность сотрудников и выручку добавляйте только тогда, когда без них нельзя отделить нужные компании или роли.

Поле **«Включить должности»** ищет конкретное слово или фразу в названии должности. Если после его добавления результатов стало слишком мало, уберите точную должность и вернитесь к управленческому уровню и функции.

![Пример выбора управленческого уровня и конкретной должности](https://dealrocket.ru/app/assets/2-2.png)

*Точная должность и числовые ограничения — необязательная часть поиска.*

## Частые вопросы { #faq }

### Почему результатов слишком мало?

Проверьте, не указали ли вы точную должность, только одну индустрию или слишком узкую географию. Убирайте эти условия по одному и смотрите, какие компании и сотрудники возвращаются в результаты.

### Почему находится много сотрудников, но не тех ролей?

Проверьте выбранные управленческие уровни и направления работы. Если вы использовали точную должность, попробуйте убрать её и посмотреть сотрудников с похожей зоной ответственности.

### Что делать, если часть компаний подходит, а часть нет?

Найдите общий признак неподходящих компаний и добавьте его в исключения. Отдельные случайные компании можно удалить позже из сохранённого списка.
