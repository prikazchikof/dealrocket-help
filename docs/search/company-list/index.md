Этот сценарий подходит, если целевые компании уже известны, но вам нужно найти сведения о них, сотрудников и доступные контакты. В DealRocket можно использовать обычные фильтры или запустить обогащение списка сайтов.

**Также ищут:** «как найти ЛПР по списку компаний», «как искать по ИНН», «как загрузить сайты компаний», «как обогатить свою базу».

## Выберите обычный поиск или обогащение { #choose-method }

| Что использовать | Подойдёт, если | Что получится |
|---|---|---|
| Фильтры в группе **«Компания»** | Есть названия, сайты или ИНН | Найдёте компании и сотрудников по текущим данным DealRocket |
| **«Обогатить базу»** | Есть список сайтов | Найдёте данные DealRocket, а [DealRocket AI](https://dealrocket.ru/ai) дополнительно поищет информацию о компаниях и их сотрудниках. Обработка займёт время |

## Что подготовить { #prepare }

Для обычного поиска подготовьте названия, сайты или ИНН — по одному значению на строку. Для обогащения нужен список сайтов компаний.

## Способ 1. Используйте фильтры по компаниям { #regular-search }

Откройте группу фильтров **«Компания»** и выберите один из трёх способов.

<span id="names"></span>
<span id="sites"></span>
<span id="inn"></span>

| Способ | Количество результатов | Точность совпадений |
|---|---|---|
| **По названию компании** | Максимальное | Самая низкая: могут найтись одноимённые и похожие компании |
| **По сайту** | Среднее | Средняя: сайт точнее связывает запрос с компанией |
| **По ИНН** | Минимальное | Максимальная: ИНН указывает на конкретное юридическое лицо |

Поиск по названию используйте, когда важно охватить максимум компаний. Вводите бренд, полное или сокращённое название. Результаты нужно проверить вручную.

Поиск по сайту даёт меньше совпадений, но они точнее. Вставляйте основной домен компании, например `company.ru`.

ИНН даёт наиболее точное совпадение, но доступен не для всех записей DealRocket. Поэтому по тому же списку он может найти меньше компаний и сотрудников.

## Способ 2. Обогатите список сайтов { #enrichment }

Если у вас есть сайты компаний, откройте **«Обогатить базу»**.

1. Вставьте по одному сайту на строку.
2. Нажмите **«Запустить обогащение»**.
3. После завершения откройте результат в разделе **«Мои списки»**.

Во время обработки можно продолжать работать в других разделах DealRocket. Сервис сопоставит сайты с текущими данными и дополнительно поищет открытые сведения о компаниях и сотрудниках при помощи [DealRocket AI](https://dealrocket.ru/ai).

## Добавьте сотрудников { #roles }

После того как компании найдены, выберите ЛПР и сотрудников, через которых можно на них выйти. Управленческий уровень, функцию и поиск по должностям мы уже разобрали в [шаге 3 инструкции по поиску новых клиентов](../index.md#seniority).

## Почему результат может быть неполным { #limitations }

Название может совпасть с другой компанией, сайт может отсутствовать в источнике, а ИНН — не быть связан с найденной записью. При обогащении сайт также может быть недоступен или не содержать сведений о сотрудниках.

Если компания не нашлась одним способом, попробуйте другой: название даёт больший охват, сайт повышает точность, а ИНН помогает проверить конкретное юридическое лицо.

## Частые вопросы { #faq }

### Можно ли обогатить список только по ИНН?

ИНН можно вставить только в одноимённый фильтр обычного поиска в группе **«Компания»**.

### Почему по сайту находится меньше сотрудников, чем по названию?

Сайт указан не во всех источниках. Название охватывает больше записей, но среди них чаще встречаются одноимённые или похожие компании.

### Почему при поиске по названию появились неподходящие компании?

Названия могут совпадать или содержать одинаковые слова. Попробуйте сайт или ИНН, чтобы точнее указать нужную организацию.

### Что делать, если у компании нет прямых контактов сотрудников?

Проверьте общие контакты компании, социальные сети и других сотрудников. Дополнительные варианты описаны в статье [о контактах](../../contacts/index.md#no-direct-contact).
