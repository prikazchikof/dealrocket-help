# Как найти сотрудников по своему списку компаний

Этот сценарий нужен, когда компании уже собраны в CRM, таблице или рабочем списке, но в нём не хватает нужных сотрудников и способов связи. Вам не нужно заново описывать весь рынок: передайте DealRocket известные названия, сайты или ИНН, а затем выберите роли внутри найденных организаций.

**Также ищут:** «как найти ЛПР по списку компаний», «как искать по ИНН», «как загрузить сайты компаний», «как обогатить свою базу».

## Выберите обычный поиск или обогащение { #choose-method }

В DealRocket есть два близких, но разных способа работать со своим списком.

| Если у вас есть | Что использовать | Что получится |
|---|---|---|
| Названия, сайты или ИНН | Фильтры в группе **«Компания»** | Текущая поисковая выдача, которую можно сразу проверять и уточнять |
| Подготовленный список сайтов | **«Обогатить базу»** | Отдельная фоновая обработка и новый результат в разделе **«Мои списки»** |

Обычный поиск удобен для быстрой проверки и сочетания разных идентификаторов. Обогащение полезно, когда есть готовый набор доменов и вы хотите дополнительно поискать сведения на сайтах компаний и в социальных сетях.

## Что подготовить { #prepare }

Приведите исходную таблицу в понятный вид: одна компания — одна строка, а названия, сайты и ИНН находятся в отдельных колонках. Уберите пустые строки и очевидные повторы. Для сайтов оставьте основной домен компании, например `company.ru`, без ссылки на новость, карточку товара или раздел сайта.

Отдельно определите, кого будете искать внутри компаний: управленческий уровень, функцию и допустимые варианты должностей. Если просто загрузить список организаций без роли, выдача может оказаться слишком широкой.

## Способ 1. Найдите компании в обычном поиске { #regular-search }

Откройте группу фильтров **«Компания»**. Значения вставляйте по одному на строку. Начните с того идентификатора, который заполнен лучше всего, а затем сравните результат с другими вариантами.

### Поиск по названию компании { #names }

Название обычно даёт больше совпадений. Вместе с нужной организацией могут появиться одноимённые компании и организации, в названии которых встречается тот же фрагмент.

Учитывайте разные варианты: бренд, полное юридическое название, сокращение, русское и латинское написание. После поиска просмотрите найденные компании. Повторяющийся неподходящий тип можно исключить по характерным словам в описании, а единичную строку — удалить позже из сохранённого списка.

### Поиск по сайтам { #sites }

Сайт точнее связывает запрос с конкретной организацией. Используйте основной домен без протокола и лишнего пути. Если часть компаний не нашлась, не делайте вывод, что их нет в DealRocket: ссылка на сайт заполнена не в каждом источнике. Проверьте эти строки отдельно по названию.

### Поиск по ИНН { #inn }

ИНН даёт точное совпадение там, где юридический профиль связан с найденной записью. При этом у данных из сайта или социальной сети ИНН может отсутствовать. Поэтому поиск только по ИНН способен вернуть меньше сотрудников, чем поиск тех же компаний по названию или сайту.

Для полноты пройдите список последовательно: сначала названия, затем сайты и ИНН для проверки спорных совпадений. Сохраняйте полезные результаты, чтобы не потерять их между вариантами поиска.

## Добавьте роли сотрудников { #roles }

Когда нужные организации найдены, выберите **«Управленческий уровень»** и **«Функцию или департамент»**. Эти поля учитывают разные варианты названий похожих ролей. Точную должность добавляйте только тогда, когда она действительно обязательна.

Например, если вам нужны руководители IT, сначала выберите руководящий уровень и функцию «Информационные технологии». Посмотрите найденные должности, а затем при необходимости исключите явно неподходящие или добавьте точную специализацию.

Проверьте несколько исходных компаний вручную: нашлась ли сама организация, есть ли сотрудники нужной функции, не относится ли человек к одноимённой компании. Только после этого сохраняйте или экспортируйте весь результат.

## Способ 2. Запустите обогащение списка сайтов { #enrichment }

Если у вас есть готовые домены, откройте **«Обогатить базу»**. Текущий экран принимает именно сайты компаний.

1. Вставьте по одному основному домену на строку.
2. Проверьте, что в строках нет комментариев, лишних путей и параметров.
3. Нажмите **«Запустить поиск»**.
4. Можно продолжить работу в других разделах: обработка выполняется в фоне.
5. После завершения откройте новый результат в разделе **«Мои списки»**.

DealRocket сопоставляет сайты с компаниями и ищет связанные сведения в доступных источниках. Полученный список — не готовая рассылка: сначала проверьте компании, роли и доступные поля, затем отберите нужные строки.

## Почему результат может быть неполным { #limitations }

У одного списка может быть несколько причин неполного результата. Сайт бывает недоступен, не содержит сведений о команде или не связывается с нужной компанией. У найденной организации могут отсутствовать сотрудники выбранной функции, а у сотрудника — опубликованный прямой телефон или email.

Если отдельная компания не нашлась:

1. оставьте в строке только основной домен;
2. попробуйте название бренда и юридическое название в обычном поиске;
3. проверьте ИНН, если он известен;
4. временно уберите точную должность и используйте функцию;
5. при повторяющейся ошибке сохраните несколько примеров и [напишите в поддержку](https://t.me/dealrockets).

## Частые вопросы { #faq }

### Можно ли обогатить список только по ИНН?

Текущий экран **«Обогатить базу»** принимает сайты. ИНН можно вставить в одноимённый фильтр обычного поиска, найти связанные записи и затем выбрать сотрудников.

### Почему по сайту находится меньше людей, чем по названию?

Не каждый источник содержит ссылку на сайт. Название охватывает больше вариантов, но требует внимательнее проверять совпадения. Используйте оба способа последовательно.

### Что делать, если у компаний нет прямых контактов сотрудников?

Проверьте общие контакты компаний, ссылки на социальные сети и другие роли той же функции. Дополнительные варианты описаны в статье [о контактах](../../contacts/index.md#no-direct-contact).
