# Как найти контакты в крупном бизнесе

Если вы занимаетесь точечными продажами крупному бизнесу, лучше искать не по общим фильтрам, а по заранее составленному списку компаний. Так важная компания не потеряется из-за ошибки поиска или отсутствующих данных.

**Также ищут:** «как найти ЛПР в крупной компании», «как искать по группе компаний», «как найти контакты в банках и корпорациях», «как работать со списком ключевых клиентов».

## Шаг 1. Подготовьте список компаний { #prepare }

Добавьте известные варианты названия бренда, юридические лица, сайты и ИНН. Если вы работаете с группой компаний, включите нужные дочерние организации и направления.

Не обязательно собирать все варианты заранее. Начните с того, что уже известно, а недостающие названия добавляйте после просмотра результатов.

## Шаг 2. Найдите компании { #names }

Сначала ищите по названию: так вы получите максимальное количество результатов. Затем используйте сайты и ИНН, чтобы уточнить совпадения и найти нужные юридические лица.

- Название даёт больше результатов, но среди них могут быть одноимённые компании.
- Сайт точнее связывает запрос с конкретной организацией.
- ИНН даёт наиболее точное совпадение, но указан не для всех записей DealRocket.

Если в результатах появились неподходящие компании, исключите их по характерным словам в описании. Подробнее об этом — в статье [«Как убрать нерелевантные компании»](../refine/index.md).

## Шаг 3. Найдите ЛПР и сотрудников, через которых можно на него выйти { #department }

В крупной компании не ограничивайтесь одной должностью. Сначала выберите подходящие значения в фильтре **«Управленческий уровень»**, а затем — нужную **функцию или департамент**.

Если нужную специализацию не удалось найти через функцию, добавьте ключевые слова в расширенный фильтр по должностям. Так можно найти не только ЛПР, но и руководителей смежных направлений или сотрудников, через которых проще выйти на нужного человека.

## Частые вопросы { #faq }

### Почему по ИНН не видны все сотрудники группы?

ИНН относится к конкретному юридическому лицу и указан не во всех источниках с сотрудниками. Проверьте другие юридические лица, сайты и варианты названия бренда.

### Что делать, если у бренда слишком много ложных совпадений?

Добавьте сайт или ИНН, а повторяющийся тип неподходящих компаний исключите по описанию. Меняйте по одному условию, чтобы не потерять нужные организации.
